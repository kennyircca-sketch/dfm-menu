Hosting & Firebase Setup
Follow these steps once to go live. Free forever.
Step 1 — Upload to GitHub Pages (Free Hosting)
1
Open GitHub on your phone browser
Go to github.com → tap the + button → New repository
2
Create the repository
Name it dfm-menu · Set to Public · Tick "Add a README file" · Tap Create repository
3
Upload this HTML file
Inside the repo tap Add file → Upload files → choose this downloaded HTML file → rename it index.html → tap Commit changes
4
Turn on GitHub Pages
Tap Settings (top of repo) → scroll to Pages → under Source choose main branch → tap Save.

Your live URL will be:
https://YOUR-GITHUB-USERNAME.github.io/dfm-menu/Wait 2 minutes then open that URL — your menu is live! 🎉
Step 2 — Connect Firebase (Real-Time Orders)
5
Create a free Firebase project
Go to console.firebase.google.com → Add project → name it dfm-menu → skip Analytics → Create project
6
Add a Web App
In Firebase console tap the </> (Web) icon → nickname it DFM Menu → tap Register app → you will see your config object like this:
apiKey: "AIza..."
authDomain: "dfm-menu-xxxx.firebaseapp.com"
databaseURL: "https://dfm-menu-xxxx-default-rtdb..."
projectId: "dfm-menu-xxxx"Copy all of it.
7
Enable Realtime Database
In Firebase sidebar → Build → Realtime Database → Create Database → choose any location → start in Test mode → Enable
8
Paste config into this file
Open the HTML file in a text editor (on phone: use Acode app — free on Play Store) → find this section near the top of the JavaScript:
const FIREBASE_CONFIG = {
apiKey: "PASTE_YOUR_API_KEY_HERE",
...Replace the placeholder values with YOUR config values → save the file → re-upload to GitHub (same steps as Step 3 above) → commit
9
Done! Test it
✓ Open the live URL on your phone (customer view)
✓ Open the same URL on another phone or tablet (staff view — tap bottom-right corner 5× → PIN 1234)
✓ Place a test order on the customer phone
✓ Watch it appear instantly on the staff tablet!

Change the PIN — search for const STAFF_PIN = '1234'and change 1234 to your own PIN before going live.

Repeat for each table. The QR URL will be:
